# Arte del creador

Colección original realizada para TriDnD (2026): doce retratos de clase generados para el proyecto, nueve ilustraciones vectoriales de especie y una ilustración vectorial de respaldo para la biblioteca del DM. Los SVG de clase se conservan como respaldo si no se puede cargar el retrato principal.

Dirección visual común de las clases: retrato vertical de selección de personaje, fantasía oscura pintada con realismo estilizado, figura única desde las rodillas, fondo de piedra o bosque con poco contraste, halo astral discreto, luz dorada desde la izquierda y relleno verde azulado. Cada clase se distingue por pose, indumentaria, objeto o magia; no hay texto, logotipos, marcas de agua ni personajes reconocibles. Los originales se generaron con la herramienta de generación de imágenes de OpenAI y las versiones de uso se optimizaron a WebP.

Dirección visual de las especies y respaldos: retratos de fantasía grabados, luz de cobre, verdes de bosque y marcos astrales. Cada pieza es ilustración orientativa y nunca modifica la ficha ni representa una apariencia obligatoria de una clase o especie.

Todo el arte que consume la interfaz es estático, local y versionado. No se descarga ni se genera ninguna imagen durante el uso del creador; tampoco requiere fuentes, librerías ni conexión externa.
