# Arte del creador

Colección original realizada para TriDnD (2026). El creador dispone de **24 piezas generadas**: 12 retratos de clase, 9 retratos de especie, un comodín propio para clases del DM, otro distinto para especies del DM y la imagen `preview-sin-forjar` con la que comienza la ficha lateral. Los SVG se conservan como fallbacks locales si un retrato principal no se puede cargar.

Las piezas se crearon con la herramienta integrada de generación de imágenes de OpenAI y se curaron y optimizaron para la interfaz. Comparten una dirección de prompt: retrato vertical de fantasía oscura, realismo pictórico estilizado, figura única, fondo sobrio de piedra o bosque, marco astral discreto, luz de cobre o dorada y contraste verde azulado. Las variantes cambian silueta, pose, indumentaria y símbolos para distinguir clases, especies y comodines; `preview-sin-forjar` representa una identidad todavía en construcción. Ninguna imagen incluye texto, logotipos, marcas de agua ni personajes reconocibles.

Cada retrato es una referencia visual y no impone la apariencia del personaje. Esta colección se sirve como recursos estáticos, locales y versionados: mostrarla no llama a ningún generador ni servicio externo. El retrato personal mantiene aparte sus acciones explícitas de subir o generar. Estos recursos no añaden reglas, no modifican el modelo de datos y no son fuente de verdad de la ficha.
