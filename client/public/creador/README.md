# Arte del creador

Colección original de 22 ilustraciones vectoriales realizadas para TriDnD (2026): doce clases, nueve especies del SRD y una ilustración de respaldo para la biblioteca del DM.

Dirección visual: retratos de fantasía grabados, luz de cobre, verdes de bosque y marcos astrales. Cada pieza tiene silueta, vestuario y atributos propios; es ilustración orientativa y nunca modifica la ficha. No representa una apariencia obligatoria de ninguna clase o especie.

Autoría: arte SVG propio del proyecto, sin imágenes ni marcas de terceros. Los archivos son estáticos y versionados. No se descargan ni se generan imágenes durante el uso del creador. Las piezas pueden editarse como vectores; no requieren librería, fuente o conexión externa.
